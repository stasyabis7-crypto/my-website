# Главная

Публичный вход остаётся в `/index.html`, поэтому адрес сайта не меняется.

- `data/projects.js` — опубликованные кейсы Главной и система тегов для фильтра.

Механика и оформление находятся в общих компонентах `components/hero-mood/`,
`components/project-feed/`. Обложки кейсов и вертикальные обложки ленты
(`feed-cover-*.webp`) лежат в `projects/<раздел>/<кейс>/covers/`.

Карта временно скрыта: карточка с `soon: true` стоит после подписки; страница
сохранена и на проде закрыта временным редиректом. Тексты карточек и баннера
берутся из сохранённого снимка редакторской таблицы. Его обновляют только
по отдельной просьбе владельца; см. `docs/languages.md`.
