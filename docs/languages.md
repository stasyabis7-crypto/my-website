# Русская и английская версии сайта

Кнопка EN / RU меняет язык текста и сохраняет выбор. На мобильном она стоит
слева от логотипа, на десктопе — справа от резюме. Кнопка использует те же
классы ДС, что и контакты: `btn--fill-glass-ui` и `btn--scroll-shadow`.

Явный `?lang=ru` / `?lang=en` важнее сохранённого выбора; язык по умолчанию —
английский. Внутренние ссылки сохраняют язык, другие параметры и якорь.
Если localStorage недоступен, выбор продолжает работать через URL.
Смена языка перезагружает текущую страницу с тем же якорем.

## Таблица текстов

Источник — [редакторская таблица](https://docs.google.com/spreadsheets/d/1ZM9ecNLEQ0Q8GL8j_FzwKSi3lRyiIKDAZ2mjzrfkPKc/edit).
Листы `main page`, `1 project`, `2 project` содержат колонки `component`, `EN`, `RU`.
Они задают Главную, CRM и «Добрую подписку» соответственно.

Тексты взяты из таблицы однократно. Деплой и сайт к таблице не обращаются.
Используется проверенный снимок `site/languages/editorial-source.json`
и созданный из него `editorial-copy.js`.
Обновлять снимок из таблицы — только по отдельной просьбе владельца.
Для такого обновления есть ручная команда `npm run copy:sync`: она читает
три публичных CSV-листа, проверяет заголовки и наличие переводов и пересобирает
словарь. Права и содержимое исходной таблицы скрипт не меняет.

Локально `npm run copy:prepare` пересобирает словарь из сохранённого снимка
без сети. `npm run check:languages` проверяет его актуальность и поведение.
`data-copy="1 project:9"` ссылается на строку 9 соответствующего листа.
Суффиксы `:label` / `:body` сохраняют разметку проблемы, решения и метаданных;
`:delta` / `:target` / `:value` сохраняют иконки роста в результатах.
После явно запрошенного импорта тексты в ячейках обновляются без правок HTML.
При вставке, удалении или
перестановке строк нужно обновить привязки `data-copy` и проверки.

Тексты вне таблицы переводит `site/language.js` по контекстным словарям:
`english-copy.js` содержит английские переводы русского HTML,
`russian-copy.js` — русские переводы новых английских текстов и опыта работы.
Готовые пары из английского словаря также используются в обратном направлении.
После добавления нового текста оба перевода включаются в словари и проверяются.
Пунктуация подзаголовков и неразрывные связи остаются общими для обоих языков.
В заголовке Главной `6 лет` и `6 years` переносятся вместе, в том числе во время
анимации появления слов (`site/typography-rules.js`).

## Общие английские изображения и видео

Язык интерфейса **не меняет медиа**: оба режима используют существующий
английский вариант из реестра `site/languages/media.js`.
`src`, `srcset`, постеры, отложенные видео и галереи одинаковы для RU и EN.
Исходники и прежние русские варианты сохранены. Баннер Главной не локализуется.

`npm run images:prepare` по-прежнему выполняет штатный lossless-импорт PNG
и обновляет `site/languages/media-slots.json`. В реестре `source` — общий слот,
`active.en` — английский файл либо исходник, если отдельного варианта нет.
Если английским вариантом снабжён только постер, прежнее поведение сохранено:
показывается английская картинка; существующее английское видео остаётся видео.

Обложка ленты (`feed-cover-*`) и первый кадр кейса — независимые слоты.
Пропорции ленты: крупная 3:4, обычная 5:6. Связь первого кадра и `projects.js`
проверяет `scripts/check-case-covers.js`.

## Резюме и статьи

Резюме открывается напрямую в новой вкладке, без выбора языка и попапа.
`siteLanguage.resume` выбирает локальный PDF: `/cv.pdf` для RU, `/cv-en.pdf` для EN.
Исходные файлы сохраняются без изменений; при деплое имена PDF получают хеш
содержимого через `version-gallery-assets.js`, чтобы CDN не отдавал старое резюме.
Одинаковая логика применяется в шапке, мобильном меню и на странице «Обо мне».
Аналитика сохраняет событие `resume_open` с `document_language`.

В RU показываются все 17 статей; в EN — только 7 английских статей.
Языковых бейджей нет в обеих версиях. Если есть обе публикации, RU ведёт
на русскую, EN — на английскую. Альтернативные адреса задаются в `editions`
записи статьи; без альтернативы сохраняется исходная публикация.
Ссылки содержат `hreflang` и доступное название с фактическим языком статьи.
Данные — `projects/articles/articles.js`, вывод — `components/article-catalog/`.
Статический fallback сохраняет все статьи; CSS скрывает русские в режиме EN.
В статическом HTML и динамическом каталоге бейджи отсутствуют.
Посты не входят в меню, их старые адреса ведут на Главную с выбранным языком.

## Временно скрытая карта

Кейс `projects/avito-charity/recycle-map/` и все его медиа сохранены.
Его карточка стоит сразу после «Доброй подписки», имеет `soon: true`,
не содержит ссылки и показывает «Скоро появится» / «Coming soon».
`.htaccess` временно перенаправляет оба адреса страницы карты на Главную (302),
оставляя обложки доступными. Для возврата кейса убрать `soon: true` и отдельное
правило карты из `.htaccess`; файлы восстанавливать не требуется.

Проверки перед публикацией: `npm run images:prepare`, `npm run check`,
`npm run admin:test`. Упаковка CDN проверяется в отдельной временной копии:
`version-gallery-assets.js` меняет имена файлов и подключения только для деплоя.
