# Английская версия сайта

Публичный сайт работает только на английском. Переключателя RU / EN нет.
Ссылки с прежними `?lang=ru` / `?lang=en` и сохранённый выбор RU также
открывают английскую версию; внутренние ссылки больше не добавляют `lang`.
Публикация выполняется из `main` после `npm run images:prepare` и `npm run check`.

`site/language.js` применяет английские тексты и медиа. Словарь
`site/languages/english-copy.js` обслуживает существующие русские ключи в HTML
и динамических компонентах. Новый контент можно писать непосредственно на
английском; отдельная русская версия больше не поддерживается.

## Изображения для каждого языка

Новые английские варианты кладутся **рядом с исходным файлом**, с суффиксом `-en`.
Например, для `projects/ozon-crm/customer-segments/covers/cover-laptop-2880x1800.webp`:

- `cover-laptop-2880x1800-en.webp` — английская обложка;
- исходный файл — временный общий вариант, пока локализованного ещё нет.

PNG можно добавлять с тем же именем: существующий `npm run images:prepare`
сам конвертирует его в WebP без потерь и не перезаписывает другой файл.
В `npm run dev` работают тот же импортёр и обновление языкового реестра.
После добавления картинок обновите страницу браузера.

Полный список слотов находится в `site/languages/media-slots.json`:
`source` — нынешняя картинка, `planned.ru/en` — куда положить новые файлы,
`active.ru/en` — что реально используется сейчас, `pages` — подключения.
Реестр генерируется автоматически, редактировать его вручную не нужно.
Отсутствующие варианты не запрашиваются: вместо ошибки 404 используется исходник.
Сайт переключает также `srcset`, постеры, отложенные обложки и медиа галерей.

Обложка ленты (`feed-cover-*`) и первый кадр кейса — независимые слоты.
Сохраняйте пропорции: крупные обложки ленты 3:4, обычные 5:6. При обновлении
первого кадра кейса связь с `projects.js` сохраняется через исходный путь:
один вариант используется и там, и там.

Для видео суффикс ставится перед `.mp4` / `.webm`, для постера — перед `.webp`.
Если добавлен только локализованный постер, показывается новая картинка;
ролик на прежнем языке не запускается. После добавления локализованного видео
анимация возвращается. Общий видео-баннер Главной не локализуется и не меняется.

## Статьи и посты

Опубликованная подборка — 17 статей: 7 английских и 10 русских. Если статья
есть на обоих языках, карточка ведёт на английскую версию, без дубля RU.
Названия карточек остаются английскими, бейдж EN / RU сообщает язык публикации;
ссылка также содержит `hreflang` и доступное название с языком.

Данные — `projects/articles/articles.js`, вывод — `components/article-catalog/`.
Статическая разметка в `projects/articles/index.html` повторяет этот список;
проверка сверяет ссылки. Обложки — отдельные схемы `covers/*-diagram.svg`:
чёрные линии на общем светлом фоне, без видео и изменения масштаба при наведении.
Их хешированные копии включены в `scripts/version-gallery-assets.js` перед каталогом.

«Посты» не входят в публичное меню; их старые адреса ведут на Главную.

## Обо мне

`about/index.html` — портрет, имя и должность, интерактивная диаграмма навыков,
опыт работы и образование. Опыт хранится одной английской подборкой
`data-language-content="en"` из `cv-en.pdf`. Русская подборка удалена. Сохраняются
формулировки, порядок достижений и контекст компаний из английского PDF.
Портрет —
`about/media/about-portrait.webp` (976 × 1361). На компьютере он занимает
левую половину экрана без внешних полей, на телефоне — всю ширину.
Аватар в шапке остаётся отдельным общим ресурсом.

Диаграмма перенесена из незакоммиченных файлов старого worktree `nav-ruler`;
подписи и подсказки показываются на английском. На десктопе открывается popover,
на телефоне — dialog со свайпом закрытия. Кнопки используют общую ДС.
Опыт раскрывается независимо по компаниям; первый пункт изначально открыт.

Проверки: `npm run images:prepare`, `npm run check`, `npm run admin:test`.
Проверка CDN-упаковки запускается в отдельной временной копии, так как меняет
имена подключаемых файлов. Для локального просмотра — `npm run dev`.

## Резюме

Все ссылки на резюме открывают `cv-en.pdf` (предоставленный английский PDF),
включая шапку, мобильное меню и страницу «Обо мне».

На странице «Обо мне» в шапке нет аватара и кнопки PDF; основная ссылка
на резюме в содержимом также служит источником для пункта мобильного меню.
Публичная версия использует `logo-en.svg`. Светлая часть подписи
ограничена областью фото/видео под ней; остальная часть использует цвет текста.
