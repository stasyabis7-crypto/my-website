# Кеш опубликованного сайта

Корневой `.htaccess` задаёт `Cache-Control: no-cache, must-revalidate` для HTML,
включая `/` и `/index.html`. Обычное открытие или обновление проверяет свежесть
HTML вместо повторного использования старой точки входа со старым именем скрипта.
До этой правки правило существовало только в `projects/.htaccess`; Главная
отдавалась без явного Cache-Control.

Скрипты, стили и картинки получают имена по хешу содержимого через
`scripts/version-gallery-assets.js`. Их длительный кеш сохраняется.

После FTP-деплоя запускается `node scripts/check-html-cache.js`: проверяются
реальные HTTP-ответы обоих адресов Главной. Команду можно запустить локально;
необязательный первый аргумент — базовый URL сервера.
