# Карта дизайн-системы и компонентов

ДС включает токены, готовые компоненты и правила их поведения. Основы лежат
в `styles/`, готовые компоненты — в `components/`, контент — рядом со страницами.
Для новой страницы переиспользуем эти источники, без копирования их CSS/JS.

## Основы

| Что | Единственный источник |
| --- | --- |
| Семейства, размеры, текстовые роли и ритм | `styles/typography.css`; загрузка файлов — `styles/fonts.css` |
| Темы и цвета | `styles/theme.css`, `site/theme.js` |
| Отступы секций | `styles/spacing.css`, токен `--space-section` |
| Масштаб и контейнер | `styles/scale.css`; не масштабировать текст повторно |
| Форма карточек | `styles/card-tokens.css` — общая закреплённая зависимость |
| Иконки | `components/icons/icons.css`, `components/icons/` |
| Аватар, логотип, favicon | `components/site-brand/` |
| Кнопки и состояния | `styles/buttons.css`; общий press-feedback и старый hover футера — `styles/button-hover.css` |

Заголовки: `.text-display-lg`, `.text-display`, `.text-h1`–`.text-h3`.
Текст: `.text-body`, `.text-body-lg`, `.text-body-sm` (различается длина строки).
Служебные роли: `.text-label`, `.text-overline`, `.text-button`.

Во всех подзаголовках сайта из одного предложения завершающая точка не ставится:
«Поиск пунктов приёма.» → «Поиск пунктов приёма». У нескольких предложений
пунктуация остаётся. Вопросы, восклицания, многоточия, сокращения и инициалы
сохраняются. Новый подзаголовок помечается `data-subtitle` вместе с `.text-body*`.
`site/typography-rules.js` применяет правило также к динамическим карточкам,
тултипам и обновлённому тексту; обычные абзацы статьи не считаются подзаголовками.

Кнопка: `.btn` + одна заливка из `buttons.css` + необязательная компоновка
`.btn--icon-left/right/top/only`. Общая высота — `--button-height`.
Доступные заливки: `pink`, `white`, `ink`, `character`, `toc`, `toc-trigger`, `deck`.
Последние четыре специализированы для существующих компонентов; обычные действия
используют `pink`/`white`. Иконке без подписи нужен `aria-label`.
Бейджи «В работе» — отдельные некликабельные элементы, без `.btn`.

## Компоненты и механика

[Баннер страницы](../components/page-hero/README.md) имеет два варианта: сферы
на Главной и картинка на внутренних страницах. Тексты, медиа и кнопка — параметры
страницы: при наличии ссылки кнопка открывает прод, иначе прокручивает вниз.
Их не нужно приводить к контенту Главной или ради них переписывать механику.

## Границы и исключения

Не всё унифицировано до одного CSS-класса. Старые контролы шапки/футера остаются
эталонными исключениями по `AGENTS.md`; новые контролы их исключения не расширяют.
В `footer.css` остаются исторические размеры подписей, в `case-blocks.css` и
`case-cards.css` — компонентные текстовые правила на токенах ДС. Их изменение
может изменить утверждённый вид и не относится к удалению неиспользуемого кода.

`dev/previews/` и `dev/grid/` содержат локальные стенды и их собственные CSS/JS.
Это не рекомендуемые источники для новой страницы. Неподключённые скрипты и шрифты прежних демонстраций `works/` удалены;
их можно восстановить из истории Git.
Исходники обложек и заготовки кейсов не считаются мусором только из-за отсутствия ссылок.

## Автоматическая защита

`npm run check` выполняется локально и перед деплоем:

- Каркас и хеши баннера, шаблон и хеши галереи, без автоматического обновления эталона.
  У баннера допускается разный контент; отдельно проверяются сферы/картинка и прод/прокрутка.
- Проверка жестов и очереди переходов настоящего кода галереи.
- Кнопки в HTML и строковой разметке JS: базовый `.btn`, известная заливка,
  одна компоновка иконки, отсутствие `.btn` на некликабельных элементах.
- `font-family` через токены ДС; комментарии не считаются кодом.
- Локальные `src`, `href`, `poster`, `srcset`, CSS `url()` и `@import`.

Это статические проверки, не полный CSS/JS-анализатор: динамические `createElement`,
вычисляемые URL/классы, назначение обычной ссылки как действия, собственные размеры,
цвета и визуальные переопределения требуют ревью. Внешние ссылки и существование
якорей проверка ресурсов не проверяет. Стенды исключены из проверки ДС, но их
локальные подключения проверяются. Неподключённость файла сама по себе не даёт
права удалять контент или исходники.
