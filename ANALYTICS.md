# Аналитика сайта

Сайт поддерживает Google Analytics 4 и Яндекс Метрику без сторонних библиотек.

## Подключение

1. Создайте веб-поток в Google Analytics 4 и скопируйте Measurement ID формата `G-XXXXXXXXXX`.
2. Создайте счётчик в Яндекс Метрике и скопируйте его числовой ID.
3. Вставьте оба значения в `styles/analytics-config.js`.
4. Опубликуйте сайт и проверьте визит в отчёте Realtime обеих систем.

Если оставить один ID пустым, будет работать только вторая система. Если пусты оба, внешние скрипты аналитики не загружаются.

## События

| Событие | Что означает |
| --- | --- |
| `resume_open` | Открытие PDF-резюме |
| `telegram_open` | Переход в Telegram |
| `works_cta_click` | Клик по CTA к работам |
| `project_impression` | Не менее 50% карточки работы видно на экране |
| `theme_change` | Переключение светлой/тёмной темы |
| `scroll_depth` | Достижение 25%, 50%, 75% или 90% страницы |
| `scroll_to_top` | Клик по кнопке «Наверх» |
| `outbound_click` | Переход на другой внешний сайт |
| `engaged_30_seconds` | Страница оставалась видимой 30 секунд |

В GA4 события появляются автоматически. В Яндекс Метрике для использования события как конверсии создайте цель типа «JavaScript-событие» с тем же идентификатором.

Для локальной проверки временно включите `debug: true` в конфигурации: события будут видны в консоли браузера. Перед публикацией верните `false`.
