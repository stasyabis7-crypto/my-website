# Ассеты для примерки сетки v2

Не связано с боевыми `works/*` — это отдельная песочница на ветке
`grid-redesign-test`, чтобы примерить новую сетку с реальными
картинками/видео до переноса на лендинг.

## Как класть файлы

Внутри уже созданы 40 папок по числу проектов из списка, названы
`{номер}-{kebab-case-title}` — тот же порядок, что в `grid-test.html`.
Кладите файл обложки прямо внутрь нужной папки под именем `cover`:

- изображение — `cover.jpg` / `cover.png` / `cover.webp`
- видео — `cover.mp4` / `cover.webm`

Можно заполнить не все 40 — сколько положите, столько и подтянется,
остальные слоты останутся плейсхолдерами.

Когда что-то добавите — скажите, я пересоберу `grid-test.html`
(смотреть через локальный сервер — `python3 -m http.server`, для
видео это единственный способ; картинки смогу ещё продублировать в
захостенном превью).
