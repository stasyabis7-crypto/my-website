# Слайдер проектов

На Главной заменяет прежнюю works-grid. Не меняет hero, шапку и футер.

- `avito.js` — единый источник параметров десяти карточек: title, description, href, image, srcset, format (`phone`, `desktop`, `square`), color.
- `project-slider.js` — общий рендер карточки и поведение любого `[data-projects]` с соответствующей коллекцией в `window.projectCollections`.
- `project-slider.css` — компоновка, обложки и типографические отступы. Кнопки оформлены исключительно через `styles/buttons.css`, текст — через роли ДС.
- Новая опубликованная страница: указать `href` карточки. Бейдж заменится вырезом с кнопкой, вся обложка станет ссылкой. Текущий кейс есть только у карты переработки.
- Между стрелками — общее число проектов из коллекции, без текущего номера и ссылки на будущую страницу.
- Цвета заданы смешанной повторяющейся последовательностью, включая разные цвета на стыке последней и первой карточек.
- Три копии списка обеспечивают непрерывное движение в обе стороны. После анимации позиция незаметно возвращается в среднюю копию. Кнопки, клавиатура, свайп и горизонтальный трекпад сдвигают по одному проекту; в зоне карточек вертикальное движение отключено, диагональные свайпы используют только горизонтальную составляющую; за пределами карточек страница прокручивается обычным образом.
- WebP в `assets/covers-avito/`: варианты шириной до 640 и 1280 px, quality 86, method 6, сохранённая прозрачность. Оригиналы в `assets/covers avito/` не изменялись. PNG на страницу не загружаются.
- Для добавления нескольких картинок в будущем можно расширить параметры карточки; сейчас используется одна обложка, без вложенного слайдера.

Проверки: `node scripts/check-design-system.js`, `node scripts/hero-mood-component.js`.

Свайп можно начать во время доводки предыдущего: слайдер подхватывается в текущей видимой позиции. Короткий быстрый жест учитывает скорость; смена высоты мобильного окна не сбрасывает движение.
