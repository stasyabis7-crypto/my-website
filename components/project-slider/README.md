# Компонент коллекции проектов

Историческое имя `project-slider` сохранено для подключений и CSS-классов. Теперь компонент всегда выводит обычную сетку — без горизонтальных жестов, дубликатов карточек, градиентных масок, стрелок и счётчиков.

- `avito.js`, `ozon.js` — параметры карточек: title, description, href, image, srcset, format (`phone`, `desktop`, `square`), color.
- `project-slider.js` — единый рендер и тултипы только для обрезанного текста.
- `project-slider.css` — раскладка. До 600 px одна колонка, от 600 px две. Горизонтальный промежуток 16 px; вертикальный 40 px на телефонах/планшетах, 56 px на десктопе от 1200 px с мышью.
- Заголовки и текст — роли `styles/typography.css`; кнопки — только из `styles/buttons.css`.
- У Avito текст находится под обложкой, отступ 24 px, между заголовком и описанием 8 px. `href: null` даёт бейдж «В работе»; ссылка добавляет вырез и белую круглую кнопку.
- У Ozon `data-card-variant="panel"`: белая карточка с текстом сверху, квадратная обложка снизу. Фон секции следует теме. Сейчас ссылки отсутствуют, кнопок и бейджей нет. Добавление `href` делает всю карточку ссылкой и добавляет первичную цветную кнопку. Текстовая часть без минимальной высоты: отступы сверху и снизу равны — 24 px на телефонах, 32 px от 600 px. Белые карточки не растягиваются по высоте соседей. Между белыми карточками всегда 16 px по обеим осям.
- Увеличение изображения на десктопе — только у кликабельных карточек. Проекты Ozon 4–7 заполняют квадрат целиком.
- WebP подготовлены в 640/1280 px, quality 86, method 6, с прозрачностью; PNG-оригиналы не изменены и не загружаются сайтом.
- Между коллекциями — `--space-section` из `styles/spacing.css`: 48/60/80 px. Страница проекта использует тот же токен через `--case-block-gap`.

Проверки: `node scripts/check-design-system.js`, `node scripts/hero-mood-component.js`.
