# Баннер страницы: общая структура, переменные данные

Баннер — семейство двух вариантов. Страницы не обязаны повторять текст или
иллюстрацию Главной. Контент уже хранится в HTML соответствующей страницы;
дополнительный рендерер и копия механики не нужны.

| Параметр | Главная | Внутренняя страница |
| --- | --- | --- |
| Контейнер | `.mood-hero` | `.mood-hero.project-hero` |
| Заголовок | `.mood-title.text-h1`, свой текст; H2 до 600 px | `.mood-title.text-h1`: H2 до 600 px, далее H1 |
| Подзаголовок | `.mood-subtitle.text-body`, свой текст | Та же роль, свой текст |
| Визуальная часть | Белые сферы `.hero-spheres` на тёмном фоне | `.mood-exhibit.project-hero__art` с `.project-hero__image` |
| Основное действие | Ссылка на прод, если он есть; иначе якорь содержимого | То же правило |

Картинка (`src`, `srcset`, размеры и альтернативный текст), заголовок,
подзаголовок, подпись кнопки и её адрес — параметры конкретной страницы.
Заготовки кейсов без этого баннера пока остаются в прежней разметке.

Заголовок страницы — единственный `h1`; разделы ниже — `h2`, их подразделы —
`h3`. Уровень HTML не задаёт размер: существующие классы `.text-*` сохраняются.
Содержательные картинки имеют описательный `alt`, а их контейнеры не скрываются
через `aria-hidden`. Пустой `alt` остаётся у декоративных изображений.

## Кнопка

Общие классы: `.mood-primary.btn.btn--fill-pink.btn--icon-right`.

- Есть адрес прода: `href` на этот адрес, подпись по смыслу страницы,
  `.icon--arrow-diagonal`. Для открытия в новом окне —
  `target="_blank" rel="noopener noreferrer"`.
- Адреса прода нет: `href="#id-содержимого"`, подпись по смыслу страницы,
  `.icon--down`. Цель с таким `id` должна существовать на странице.

Отсутствие ссылки на прод задаётся контентом, а не проверкой доступности сайта
из браузера. Никакого сетевого запроса для выбора действия не нужно.
Ссылка остаётся обычным `<a>`: переход на прод и якорь работают без JavaScript;
общая навигация уже обслуживает плавную прокрутку. Новый обработчик клика не нужен.

## Источники и защита

- Общая раскладка: `components/hero-mood/hero-layout.css`, типографика и кнопки — ДС.
- Сферы Главной: [hero-mood](../hero-mood/README.md), закреплённые CSS/JS.
- Внутренний вариант и появление картинки: `components/page-hero/page-hero.css/js`.
- `node scripts/check-page-heroes.js` проверяет оба варианта и оба действия,
  не сравнивая тексты, картинки или URL разных страниц между собой.
- Проверка Главной фиксирует каркас, CSS/JS и сферы, но допускает разные
  тексты заголовка, подзаголовка, подпись/адрес и вариант основной кнопки.
  `--sync` сохраняет текущий контент Главной. Эталон не переписывается автоматически.

При смене картинки или длины текста проверить переносы и высоту баннера на
мобильной и десктопной ширине. Это проверка контента, а не повод переписывать
поведение всего компонента.

Картинка внутреннего баннера прижата к нижнему краю цветной поверхности на
всех ширинах. `margin-top: auto` у `.project-hero__image` сохраняется и на
мобильных: свободное место высокой строки остаётся над картинкой, не под ней.
Проверять также высокие мобильные окна (например, 390 × 1100), где содержимое
короче минимальной высоты баннера; нижний край картинки совпадает с краем
`.mood-stage` без цветной полосы снизу.

Заголовки всех баннеров используют H1 из ДС, на телефонах до 600 px — размер
H2. Семантический тег остаётся `h1`. Размер меняется только по брекпоинтам
ДС: без плавного масштабирования и JavaScript-подгонки по длине слова.
Правила размеров находятся в `styles/typography.css`.

Для широких мокапов (CRM) используется `.project-hero--landscape`: картинка
увеличена и обрезается справа на всех экранах, левый край закреплён.
На телефонах и планшетах ширина картинки — 160% контейнера; центрирования нет.
На десктопе используется `clamp(720px, 66vw, 1200px)` с той же обрезкой справа;
нижний край остаётся прижат к баннеру. Появление этого варианта — всегда справа,
на всех устройствах, после открытия шторок перехода; 1100 мс,
`cubic-bezier(.22,1,.36,1)`. Reduced motion отключает появление.

Это утверждённый вариант для раздела CRM и всех его будущих кейсов.
`check-page-heroes.js` проверяет наличие модификатора у каждого баннера
в `projects/ozon-crm/`. Менять размер/кадрирование и анимацию этого варианта
можно только по явной просьбе пользователя. Картинка и тексты — контент страницы.
У остальных вариантов направление по-прежнему определяется колонками сетки:
справа при боковой компоновке, снизу при вертикальной.
