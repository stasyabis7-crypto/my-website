# Айдентика сайта

Единый набор ресурсов, используемых общей оболочкой:

- `avatar-portrait-v2.webp` — портрет автора;
- `logo.svg` — русский знак в шапке, `logo-en.svg` — предоставленная английская подпись; размер и маску задаёт `site-header`;
- `logo-contrast.js` — светлая часть подписи поверх фото/видео и обычная над фоном страницы, включая границу между ними;
- `favicon.webp` — иконка вкладки, подключается в `<head>` страниц.

Общие интерфейсные и социальные иконки лежат в `components/icons/`.
Изображения кейсов остаются рядом со страницами, в `projects/`.
