# Лента проектов Главной

Сетка опубликованных кейсов с переключателем платформы, как у Mobbin.

- Разметка-каркас — в `index.html` (`[data-project-feed]`): заголовок «Интерфейсы со смыслом»
  (`.text-h2`) и переключатель по центру; карточки рендерит `project-feed.js`
  из `pages/home/data/projects.js`.
- Переключатель — `.btn-segmented` + `.btn--fill-segment` из `styles/buttons.css`;
  выбор хранится в адресе (`?platform=…`), «назад» в браузере работает.
- Теги под обложкой — некликабельные подписи `.feed-card__tag` в прокручиваемой
  строке `components/chip-scroller/` (стрелки — `.btn--fill-bare`).
- Кликабельна только обложка: при наведении рамка чуть уменьшается
  (`--wg-hover-scale`), как кликабельные картинки на страницах кейсов.
- `feed-entry.js` — выравнивание по якорю `#works-gallery` при входе с другой страницы.
