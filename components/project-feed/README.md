# Лента проектов Главной

Опубликованные кейсы сразу после баннера: один под другим, на всю ширину экрана.

- Разметка-каркас — в `index.html` (`[data-project-feed]`); карточки рендерит
  `project-feed.js` из `pages/home/data/projects.js`.
- Карточка: название и описание, кнопка «Смотреть кейс» (на десктопе справа от
  текста, на телефоне под последней плиткой) и бенто-сетка.
- Бенто: 12 колонок, зазор 16px (телефон — 2 колонки, 10px). Плитки задаются в
  данных проекта; без `image` плитка показывает заглушку с размером картинки
  (2x от размера плитки при ширине сетки 1376px).
- На кейс ведёт только кнопка: плитки некликабельны и на наведение не реагируют.
- `feed-entry.js` — выравнивание по якорю `#works-gallery` при входе с другой страницы.
