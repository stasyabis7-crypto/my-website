# Лента проектов Главной

Каталог обложек сразу после баннера — без заголовка и фильтров.

- Разметка-каркас — в `index.html` (`[data-project-feed]`); карточки рендерит
  `project-feed.js` из `pages/home/data/projects.js`.
- Сетка: четыре колонки от 1000px, две крупные обложки 2×2 и пустые ячейки;
  место каждой плитки — `PATTERN` в `project-feed.js`. Ниже 1000px — две колонки.
- Пропорции точные на любой ширине, обложки не обрезаются: крупная 3:4
  (1800×2400), обычная 5:6 (1500×1800). Файл — `feed` в `projects.js`,
  отдельный от первого кадра страницы кейса.
- Под обложкой только название обычным текстом.
- Проект со страницей: обложка-ссылка и круглая стеклянная кнопка со стрелкой
  в правом верхнем углу (`.btn--fill-glass-round`). Проект без страницы
  (`soon: true`): подпись «Скоро появится» на том же месте, ссылки нет.
- `feed-entry.js` — выравнивание по якорю `#works-gallery` при входе с другой страницы.
