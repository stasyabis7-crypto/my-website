# Лента проектов Главной

Сетка опубликованных кейсов с фильтрами как у Mobbin.

- Разметка-каркас — в `index.html` (`[data-project-feed]`), всё содержимое
  рендерит `project-feed.js` из `pages/home/data/projects.js`.
- Переключатель платформы — `.btn-segmented` + `.btn--fill-segment`, чипы —
  `.btn--fill-chip`, стрелки строки тегов — `.btn--fill-bare` (всё из `styles/buttons.css`).
- Выбранные теги сужают выдачу (у проекта должны быть все). Чип, который
  оставил бы пустую выдачу, недоступен. Тег под обложкой открывает подборку
  только по нему.
- Состояние — в адресе (`?platform=…&tags=…`), «назад» в браузере работает.
- `feed-entry.js` — выравнивание по якорю `#works-gallery` при входе с другой страницы.
