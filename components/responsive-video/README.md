# Адаптивное видео

`responsive-video.js` подключается перед `case-lightbox.js` на страницах,
где один ролик имеет разные кадрирования для мобильного и десктопного экрана.

У `<video data-responsive-video>` нет `src`: браузер выбирает первый подходящий
`<source media="…" src="…">`, последний `<source src="…">` — общий вариант.
Атрибуты `data-poster`, `data-width`, `data-height` у source задают постер
и пропорции этого варианта; по умолчанию берутся атрибуты video.
При пересечении брейкпоинта компонент обновляет их и вызывает `load()`,
чтобы браузер выбрал новый источник. Исходные autoplay/muted/loop сохраняются.

Для роликов в содержимом кейса и Playground используется `lazy-video.js`
(подключить в конце body, после `responsive-video.js`). Маркер —
`data-lazy-video`, адреса у video/source — `data-src`, постер у video —
`data-poster`, `preload="none"`, без autoplay. Ширина и высота остаются
в HTML. Постер и файл подключаются за половину экрана до появления,
воспроизведение начинается только в видимой области. Вне экрана и в фоновой
вкладке видео останавливается. При reduced motion остаётся постер; без постера
подгружается первый кадр без автопроигрывания. Браузерный тест проверяет
отложенный src и остановку после прокрутки; fullscreen-галерея умеет читать
отложенные источники, включая выбранный source media.

Видео закреплённого баннера Главной и лента проектов имеют собственные
существующие контроллеры; `lazy-video.js` применяется только по явному маркеру.
