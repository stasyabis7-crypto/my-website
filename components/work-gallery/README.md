# Галерея разделов (скрытые страницы)

С 2026-09-23 Главная использует ленту `components/project-feed/`, а эта
галерея осталась только на страницах разделов `projects/<раздел>/`, которые
временно скрыты редиректами в `.htaccess`. Закрепление хешами снято вместе
с `template.html`/`baseline.json`; поведение жестов по-прежнему проверяет
`scripts/check-gallery-gestures.js`.

## Утверждённое поведение

- Длинный жест тачпада с инерцией переключает ровно одну карточку.
- Следующий отдельный жест переключает следующую карточку.
- Скролл вверх над карточкой возвращает к баннеру.
- Бесконечный цикл сохраняет положение, масштаб и соседние карточки.
- Курсор обновляет состояние под неподвижной мышью при смене карточки.
- Касания, перетаскивание и клавиатурная навигация сохраняют текущее поведение.
- Ссылки, теги, форма выреза, подписи по ширине обложки и адаптивная раскладка
  сохраняют текущий вид.
- Вход по `#works-gallery`, возврат назад и `prefers-reduced-motion` работают.

После разрешённых правок проверять эти сценарии на десктопе и мобильном,
затем обновлять только хеши действительно затронутых файлов. Хеши гарантируют
целостность закреплённых исходников, но не заменяют проверку в браузере.

Данные разделов (`pages/home/data/sections.js`) отделены от поведения: обновление контента
не требует переписывания механики компонента. При изменении ссылок нужно также
согласовать навигацию без JavaScript в шаблоне.

Альтернативный текст обложки задаётся полем `alt` в данных раздела, отдельно
от `title` (заголовка карточки и названия ссылки).
