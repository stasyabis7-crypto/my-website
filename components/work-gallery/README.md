# Закреплённая галерея Главной

Текущее рабочее состояние сохранено по просьбе пользователя. При выделении
компонента код поведения и стилей не менялся. Компонент уже существует в
`work-gallery.js` и `work-gallery.css`; `template.html` теперь хранит исходную
разметку, а `baseline.json` — SHA-256 утверждённых файлов.

## Проверка и синхронизация

- `node scripts/work-gallery-component.js` проверяет разметку Главной и хеши.
- `node scripts/work-gallery-component.js --sync` переносит шаблон в Главную,
  но не изменяет хеши. В браузере остаётся статическая разметка без загрузки шаблона.
- Проверка обязательна перед деплоем. Генерация имён ресурсов для CDN идёт после неё.

Не менять оформление или поведение галереи без явного запроса пользователя.
Не подменять эталон автоматически при ошибке проверки. Общие зависимости
закреплены, потому что изменения в них могут незаметно сломать галерею:
`page-motion.js/.css` — курсор и нахлёст секций; `layout-chrome.js` — навигация;
`gallery-entry.js` — вход по якорю; `card-tokens.css` — форма карточек.
Если отдельная разрешённая задача меняет общую зависимость, сначала проверить
галерею по списку ниже и убедиться, что её поведение не изменилось; только затем
обновить соответствующий хеш. Общие кнопки, типографика и темы по-прежнему
берутся из дизайн-системы; её правки тоже не должны менять галерею незаметно.

## Утверждённое поведение

- Длинный жест тачпада с инерцией переключает ровно одну карточку.
- Следующий отдельный жест переключает следующую карточку.
- Скролл вверх над карточкой возвращает к баннеру.
- Бесконечный цикл сохраняет положение, масштаб и соседние карточки.
- Курсор обновляет состояние под неподвижной мышью при смене карточки.
- Касания, перетаскивание и клавиатурная навигация сохраняют текущее поведение.
- Ссылки, теги, форма выреза, подписи по ширине обложки и адаптивная раскладка
  сохраняют текущий вид.
- Вход по `#works-gallery`, возврат назад и `prefers-reduced-motion` работают.

После разрешённых правок проверять эти сценарии на десктопе и мобильном,
затем обновлять только хеши действительно затронутых файлов. Хеши гарантируют
целостность закреплённых исходников, но не заменяют проверку в браузере.

Данные разделов (`pages/home/data/sections.js`) отделены от поведения: обновление контента
не требует переписывания механики компонента. При изменении ссылок нужно также
согласовать навигацию без JavaScript в шаблоне.

Альтернативный текст обложки задаётся полем `alt` в данных раздела, отдельно
от `title` (заголовка карточки и названия ссылки).
