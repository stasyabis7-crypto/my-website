# Разделы портфолио

Главная показывает только описанные кейсы из `pages/home/data/projects.js`
(лента с фильтром по тегам). Страниц-галерей разделов с квадратными обложками
больше нет: адреса `projects/<раздел>/` и незаполненные заготовки кейсов ведут
на Главную редиректами в корневом `.htaccess`.

- `concepts` — галерея изображений без переходов (скрыта редиректом).
- `articles`, `posts` — статьи и посты в Telegram.
- `playground` — концепты сеткой с полноэкранным просмотром; интерфейсы берёт из `concepts/`, плакаты и небольшие анимации — из собственного `media/`. Девять плакатов Typomania перемешаны с остальными работами; пропорции оригиналов сохранены.
  Четыре геометрические анимации (`diamonds`, `hexagons`, `triangles`, `white-network`) собраны одной квадратной плиткой 2×2 с зазором 16px на всех ширинах. Заглушки `*-poster.webp` — первые кадры соответствующих видео; загрузкой и воспроизведением управляет общий `lazy-video.js`.

Для проекта: `<раздел>/<проект>/index.html`, `covers/cover.webp`, `media/`.
Медиа кейса группируются по смыслу: `about/`, `navigation/`, `filters/`,
`favorites/`, `team/` и т. п.; новые имена файлов и папок — lowercase-kebab-case.
Страницы без описания кейса — заготовки.

Старые материалы из `works/01-*` … `works/39-*` перенесены в соответствующие
разделы. Дополнительные варианты лежат в `media/`, исходные изображения сохранены.
`projects/recycle-map/` оставлен только для перенаправления старых ссылок.
Неиспользуемые `works/fonts/` и `works/shared/` удалены; прежние реализации доступны в истории Git.

Скругление обложек задаёт
`styles/card-tokens.css`; кнопки — только `styles/buttons.css`.
