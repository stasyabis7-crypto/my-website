# Разделы портфолио

Главная читает семь разделов из `pages/home/data/sections.js`.
Обложка каждого раздела: `projects/<раздел>/assets/section-cover.webp`.
Иллюстрация баннера, если есть: `projects/<раздел>/assets/hero.webp`.

Каждый раздел лежит в `projects/<раздел>/index.html`:

- `avito-charity` — 6 проектов.
- `ozon-crm` — 6 проектов.
- `ozon-prices` — 4 проекта.
- `swtec-angel` — 6 проектов (названия разделов 3–6 пока предварительные).
- `swtec-medical` — 3 проекта.
- `concepts` — галерея изображений без переходов.
- `activities` — статьи и посты в Telegram.

Для проекта: `<раздел>/<проект>/index.html`, `covers/cover.webp`, `media/`.
Медиа кейса группируются по смыслу: `about/`, `navigation/`, `filters/`,
`favorites/`, `team/` и т. п.; новые имена файлов и папок — lowercase-kebab-case.
Пустые `covers/` готовы для новых обложек. После добавления обложки нужно
заменить `.project-card__placeholder` в карточке раздела на `<img>` и добавить
изображение на страницу проекта. Страницы без описания кейса — заготовки.

Старые материалы из `works/01-*` … `works/39-*` перенесены в соответствующие
разделы. Дополнительные варианты лежат в `media/`, исходные изображения сохранены.
`projects/recycle-map/` оставлен только для перенаправления старых ссылок.
Неиспользуемые `works/fonts/` и `works/shared/` удалены; прежние реализации доступны в истории Git.

Сетка разделов использует ширину и отступы кейса из `styles/layout.css`.
Скругление всех новых обложек и существующей сетки задаёт
`styles/card-tokens.css`; кнопки — только `styles/buttons.css`.
