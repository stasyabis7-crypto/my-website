# Баннеры CRM — утверждённый вариант

Для раздела CRM и всех новых страниц его проектов использовать общий баннер
`.mood-hero.project-hero.project-hero--landscape` с широкой картинкой ноутбука.
Источник поведения — `components/page-hero/page-hero.css/js`;
контракт — `components/page-hero/README.md`.

- Появление картинки справа на всех устройствах, включая телефоны и планшеты.
- Крупная картинка обрезается справа на всех экранах, левый край закреплён.
  На телефонах и планшетах ширина картинки — 160% контейнера; центрирования нет.
  Нижний край прижат к баннеру, горизонтального скролла нет.
- На мобильном — H1 из ДС, уменьшается только для слова, не помещающегося в строку.
- Сохранять ожидание шторок перехода и отключение анимации при reduced motion.
- Не создавать собственные CSS/JS анимации на страницах и не менять утверждённые
  параметры без явной просьбы пользователя. Меняются только контент и картинка.
- Проверка: `node scripts/check-page-heroes.js`, а также визуально на телефоне,
  планшете и десктопе. Заготовкам без херо добавлять баннер при наполнении кейса.
