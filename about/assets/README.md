# about/assets — hero-портрет

Кладите сюда файлы с этими именами — страница подхватит их сама, без правок кода
(картинки уже подключены с `onerror`-заглушкой: пока файла нет, вместо неё видна
мягкая цветная плашка с монограммой «АВ»).

| Файл | Для чего | Рекомендации |
| --- | --- | --- |
| `portrait.webp` (или `.jpg`/`.png`) | Портрет в Hero, правая колонка | вертикальный кадр, ~1000×1250px, лицо в верхней трети кадра |

Тема (light/dark) не требует отдельных версий портрета — один файл работает в обеих.
